# Portfolio de Qassim Messili

Responsable informatique en alternance et étudiant en Bac+5 Expert en architectures systèmes, réseaux et sécurité. Projets cloud (Azure, Google Cloud), Kubernetes, Windows Server, supervision et SQL Server.

Site en ligne : https://qassimmessili.github.io

## Contenu

- `index.html` : le site (une seule page, sans dépendance à installer)
- `comptes-rendus/` : les comptes rendus complets au format PDF

## Ajouter un projet

1. Déposer le compte rendu PDF dans `comptes-rendus/`.
2. Dans `index.html`, chercher `const PROJETS = [`.
3. Copier un bloc `{ ... }` existant, le coller à la suite et modifier les textes.
4. Mettre à jour le chemin du PDF dans `docs`.

Les captures des comptes rendus sont floutées : adresses IP publiques, identifiants et mots de passe.
